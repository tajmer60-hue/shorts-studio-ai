# Запуск, сборка и приёмка

## Проектное окружение (полное, с AI)

Windows 11, Python 3.11+, FFmpeg/FFprobe в `tools\` или PATH.

```
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-ai.txt
.venv\Scripts\python -m pip install -r requirements-gpu-windows.txt
.venv\Scripts\python download_speech_model.py     # ~486 MB, один раз
start.bat
```

Модель речи и кэш живут в `models\` и `cache\` и исключены из Git.

## Portable-сборка (Lite, без AI-зависимостей)

```
.venv\Scripts\python build_portable.py --target dist\Shorts-Studio-AI.zip
```

В архив попадают интерфейс, рендер, очереди, провайдеры, цензура, рефрейм,
режимы, профили и QC, но **без** numpy/OpenCV/faster-whisper: анализ ритма и
локальная значимость в Lite объяснимо отказывают и просят проектное окружение.
Распознавание речи и бенчмарк требуют полного окружения или `start.bat`.

## Что взять для первой приёмки

1. Короткий (2–5 минут) фрагмент серии, на который у вас есть права.
2. Прогон в режиме Serial Cutter без галочки облака: проверьте склейки на слух,
   вертикальный кадр, субтитры, отсутствие чёрных полос.
3. Тот же фрагмент с галочкой облака и бесплатным ключом: сравните отбор.
4. Откройте очередь QC и отметьте просмотренные сомнения.
5. Файл больше 5 ГБ: прервите обработку кнопкой и закрытием окна, затем
   запустите снова — завершённые стадии не должны пересчитываться.

## Чего приложение не обещает

- Гарантии отсутствий ограничений платформ: цензура снижает риск, не устраняет его.
- Прогноза просмотров: все баллы — относительные оценки монтажа.
- Музыки без ваших лицензированных файлов: каталог хранит ориентиры и заявленные
  статусы, микс требует файл и лицензию.
- Полного понимания каждого кадра: облако видит разреженные выборки, локальная
  значимость помечена низкой уверенностью.

## Ключи и секреты

Ключи вводятся только в поля интерфейса или в локальный `.env` (в `.gitignore`).
В репозиторий, логи и артефакты они не пишутся; тесты читают все созданные файлы
и падают, если находят в них ключ.
