# Shorts Studio AI

Локальное приложение для Windows: основа для нарезки фильмов и сериалов в вертикальные короткие видео.

## Первая версия

- Выбор большого локального видео без загрузки на сервер и без чтения целого файла в память Python.
- Ручной выбор начала и длительности отрезка в секундах.
- Вертикальный MP4 1080 × 1920: вписать с полями или обрезать по центру.
- FFmpeg работает отдельно от интерфейса; доступны прогресс и отмена.
- Исходники и существующие результаты не перезаписываются. Незавершённые экспорты удаляются при штатной отмене или ошибке.

Это ранняя версия, а не готовый автоматический AI-монтажёр. Автовыбор сюжетных сцен, распознавание речи, удаление пауз, субтитры, подавление мата, отслеживание персонажей и локальное размытие чувствительных областей пока не реализованы. Автоматическая модерация в будущем потребует проверки человеком; соответствие правилам платформ не гарантируется.

## Запуск

1. Установите Python 3.11+ с Tkinter (стандартный установщик Python для Windows).
2. Установите FFmpeg с FFprobe и кодеком libx264: оба исполняемых файла должны быть в PATH или в папке `tools` рядом с `app.py`.
3. Запустите `python app.py` или `start.bat`, если доступна команда `py`.
4. Выберите видео, введите начало и длительность, выберите кадрирование и новое имя результата.

Python-пакеты из pip не требуются. FFmpeg не включён в репозиторий. Большие файлы потребуют свободного места для результата; скорость зависит от процессора, разрешения и накопителя.

## Проверка

`python -m unittest discover -s tests -v`

Тесты проверяют диапазоны, защиту исходников, аргументы FFmpeg и режимы кадрирования. Для проверки реального экспорта необходим установленный FFmpeg. Сначала проверьте короткий фрагмент своего видео и оба режима кадрирования.

## Авторизация, токены и путь запроса

В этой версии нет сервера, аккаунтов, HTTP-запросов, паролей, OAuth или токенов приложения. Подключение GitHub в Codex используется для работы с исходным кодом и не является авторизацией пользователей Shorts Studio. Приложению не нужен токен GitHub или ключ OpenAI.

Поток: `Studio.begin()` в `app.py` получает пути и параметры → фоновый `Studio.worker()` вызывает `probe()` → `build_command()` в `render.py` проверяет диапазон → отдельный процесс FFmpeg читает локальное видео и пишет временный MP4 → результат переименовывается после успешного завершения → очередь событий обновляет интерфейс. Аргументы передаются списком без shell. Секреты не сохраняются; `.env` исключён из Git. Журнал FFmpeg временный, локальный и удаляется по завершении. Никакие видео или данные не отправляются в интернет.
