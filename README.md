# Shorts Studio AI

Локальное Windows-приложение для нарезки фильмов и сериалов в Shorts. Целевое оборудование: Windows 11, RTX 4070 Laptop 8 GB VRAM, 16 GB RAM. Без обязательных платных API.

## Что работает сейчас — M1

- PySide6: выбор видео, ручной отрезок, вертикальный MP4 1080×1920, fit/crop.
- SQLite: постоянная очередь, пауза перед следующим заданием, повтор ошибок/отмен/прерванных задач.
- После аварии задание running становится interrupted; повтор запускается вручную. Pending сохраняются и автоматически запускаются при следующем открытии.
- Отдельный поток координирует FFprobe/FFmpeg; интерфейс остаётся отзывчивым. Есть прогресс и отмена текущего задания.
- Видео читается FFmpeg с диска, фильм не загружается целиком в Python RAM.
- Исходники и существующие результаты не перезаписываются. Временный MP4 проверяется FFprobe перед переименованием.
- Сетевые протоколы входных медиа запрещены; приложение не отправляет видео в интернет.
- Анализатор референса: смены кадров, тишина, громкость, чёрные интервалы, контактный лист, метаданные.

AI-выбор сцен, Serial Cutter с пониманием сюжета, Viral Moments, расшифровка речи, автоcубтитры, Smart Censor, музыкальная синхронизация, профили каналов и видеопредпросмотр **ещё не реализованы**. Очередь восстанавливает задания, а не продолжает кодирование с последнего кадра. После аварийного завершения возможны оставшиеся временные файлы. Тестов на полнометражных многогигабайтных файлах пока нет.

## Запуск из исходников

1. Python 3.11+ для Windows с командой py.
2. Запустить setup.bat для создания .venv и установки закреплённых Python-зависимостей.
3. Поместить ffmpeg.exe и ffprobe.exe в tools/ рядом с app.py либо добавить их в PATH. Сборки доступны через [официальный сайт FFmpeg](https://ffmpeg.org/download.html). Бинарники не включены в Git.
4. Запустить start.bat.
5. Выбрать локальный файл, начало и длительность в секундах, режим кадра и **новое** имя результата.

В текущей рабочей копии зависимости и FFmpeg уже установлены. Отдельного установщика/EXE пока нет. Для экспорта используется CPU libx264; RTX пока не задействована.

База jobs.sqlite3 хранится в локальной папке данных приложения Windows. Для изолированных тестов путь можно задать переменной SHORTS_STUDIO_DATA_DIR. Два обычных экземпляра в одной папке блокируются через QLockFile.

## Тесты и референс

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
.venv\Scripts\python analyze_reference.py references/example.mp4
```

Интеграционные тесты создают синтетические медиа и проверяют реальный экспорт через FFprobe. При отсутствии FFmpeg часть интеграционных тестов пропускается. Для тестов GUI используется offscreen.

Референс остаётся в references/; кадры, метрики и логи — в cache/reference/. Эти папки исключены из Git. REFERENCE_ANALYSIS.md содержит реальные измерения и выборочный визуальный разбор пользовательского ролика. Порог смены сцены не равен смысловой монтажной границе.
