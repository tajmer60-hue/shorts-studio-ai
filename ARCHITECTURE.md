# Архитектура и проверяемый план

## Границы модулей

PySide6 — UI и подтверждение решений. Рабочие потоки/процессы — FFmpeg и модели. SQLite — задания, этапы и версии артефактов. Большие результаты — файлы в локальном cache; в очереди только ссылки и метаданные.

Import/Probe → Proxy/Scenes → Speech/VAD/ASR → Ranking → EDL → Reframe → Subtitle/Music → Censor → Preview/QC → Export.

Analysis извлекает признаки и исходные timecodes. Decision формирует объяснимые предложения и редактируемый EDL. Render исполняет только подтверждённый план. Метрики Lite не называются вероятностью вирусности или пониманием сюжета.

Планируемый EDL v1: source identity, режим, диапазон длительности, segments с source in/out, порядком, причиной, статусом подтверждения, crop keyframes, masks, speed, audio и subtitles. Все интервалы в секундах исходника, отдельная карта времени результата. Нелинейный порядок требует подтверждения.

Контракт этапа: schema/algorithm version, fingerprint входов и параметров, status, artifact paths, контрольная сумма, ошибки и timestamps. Completed записывается только после проверки артефакта. При старте незаконченный этап становится interrupted, валидные предшественники переиспользуются. Не присваивать completed только по наличию файла. P0 реализует probe cache и журнал render/QC/publish; следующие аналитические этапы добавят собственные артефакты.

Один тяжёлый AI worker; 8 GB VRAM, ограниченные proxy/кадры, последовательная выгрузка моделей. Lite полностью офлайн. Local AI использует отдельно загружаемые веса с указанными лицензией/размером. Cloud не включается и ничего не отправляет без разрешения.

## P0 — стабильность, отдельный draft PR

- Аудит/ТЗ/правила/прогресс/исключения Git.
- Защита target, безопасная отмена, журнал с ротацией, контроль диска до и во время экспорта.
- Сначала cache probe; далее durable stage journal, восстановление после render/QC/publish, проверка устаревших артефактов.
- Приёмка: реальное видео import→draft MP4, FFprobe размеров/длительности/аудио, decode без ошибок; source неизменен; существующий target сохранён.
- Принудительно остановить отдельный процесс после каждой завершённой стадии. Перезапустить: успешные стадии не пересчитываются, неполные не считаются готовыми. Проверить отмену, мало места, кириллицу и повреждённое видео.
- Пока эта приёмка не пройдена, P0 не закрывается.

## P1 — сцены, речь, предложения

- Сохраняемые сцены и шкала времени, VAD отдельно от простой амплитудной тишины.
- Локальный ASR с word timestamps; субтитры SRT/ASS; preview склеек и fades.
- Кандидаты Lite по признакам с исходными таймкодами и объяснениями; сцены не объявляются семантически сильными без модели.
- Intro/credits как предложения, без удаления текста диалоговых субтитров.
- Приёмка: разметить вручную короткие реальные русские диалоги с паузами, музыкой, перебивками; сравнить слова/таймкоды, A/V sync, прослушать склейки. Каждое исключение исправляется пользователем.

## P2 — вертикальный кадр

- Background Fill, затем детекция/трекинг лица и объекта, сглаживание и лимит скорости.
- Несколько лиц и низкая уверенность → проверка/общий план, не случайный прыжок.
- Ручные keyframes и overlay source+crop до рендера.
- Приёмка: реальные сцены с одним/двумя говорящими, уходом за край и сменой плана. Сохранение нужного объекта, пропорций и плавности проверяется визуально; метрики фиксируются с timecodes.
