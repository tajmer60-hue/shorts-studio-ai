# Приёмка автоматического монтажа

## Текущий запрет расходов

Пользователь выбрал подготовку без платных запросов. Не использовать найденные ключи, не вызывать облачный анализ за пользователя. Не выдавать mocked HTTP test за проверку модели.

## Уже выполнено локально

- Реальная склейка трёх интервалов референса, коррекция границ по распознанным словам, встроенные субтитры и заголовок.
- 720×1280, 26.166667 с со звуком, полное декодирование; кадры поступают в QMediaPlayer.
- Сохранение точных байтов, восстановление списка при повторном открытии.
- Разрешение API выключено по умолчанию; первый вызов/недостаточный лимит/timeout/кэш/отмена покрыты тестами без сети.

## Требуется после разрешения

1. Отдельный ключ OpenRouter с лимитом аккаунта; небольшой тестовый материал с разрешённой отправкой.
2. Получить реальный ответ выбранной модели. Если API/провайдер не принимает параметры, исправить явно, не переключаться молча на дорогой endpoint.
3. Сверить все интервалы и объяснения со сценами. Никаких выдуманных действий, незавершённых диалогов и повторяющихся исходных кадров.
4. Просмотреть/прослушать склейки и субтитры. ASR small может ошибаться; нужна оценка и исправление текста.
5. Полная серия: проверить сюжетную связность роликов, переходы, хронологию, фактические расходы и восстановление.
6. Только затем считать облачный отбор принятым. Сопровождение героя, цензура и музыка требуют отдельных реализаций и испытаний.

Текущий анализ использует первую аудиодорожку и разреженные изображения. Переключатель озвучки, полноценный визуальный анализ действия, музыка и маски пока отсутствуют. Монтажный процесс не имеет всех crash-гарантий старого одиночного экспорта. Незавершённый рендер может пересчитываться; служебные файлы сохраняются на D:.
