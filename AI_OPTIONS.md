# AI-монтаж: первый кандидат и границы подключения

Проверено 23 октября 2026 по официальным страницам.

Первый кандидат — Gemini 2.5 Flash-Lite. Поддерживает входное видео; есть бесплатный уровень с ограничениями. Стандартный платный тариф: $0.10 за миллион входных токенов текста/изображений/видео, $0.30 для аудио, $0.40 за миллион выходных токенов. На бесплатном уровне данные могут использоваться для улучшения продуктов; на платном в таблице указано «No». Лимиты и доступность нужно проверить для аккаунта пользователя. [Тарифы](https://ai.google.dev/gemini-api/docs/pricing).

Ключ создаётся в [Google AI Studio](https://aistudio.google.com/apikey), порядок описан в [документации ключей](https://ai.google.dev/gemini-api/docs/api-key). Ключ не присылать в чат и не коммитить. Провайдер/бюджет ещё не согласованы, ключ не запрашивался, внешние запросы с медиа не выполнялись.

Альтернатива без API — локальные модели: текущая речь работает на RTX, но локальная мультимодальная модель для смыслового монтажа ещё не выбрана/не проверена. Бесплатный ASR сам по себе не понимает сюжет.

## Как должна работать основная функция

1. Полностью разобрать хронометраж локально: речь, сцены, карта исходных таймкодов, proxy и ключевые кадры.
2. Рассматривать все последовательные окна серии, затем сделать общий отбор сильных моментов. Никакой квоты и обязательного покрытия исходника готовыми роликами.
3. Для выбранных кандидатов уточнить визуальный контекст короткими клипами/кадрами; модель предлагает название, причину и несколько исходных сегментов для монтажа.
4. Проверять ответ по схеме, запрещать несуществующие таймкоды, требовать отдельного подтверждения нелинейного порядка. Затем собрать предпросмотр и получить подтверждение пользователя.
5. Перед отправкой: показать объём/состав материалов и оценку цены, ограничить бюджет и число запросов; сохранить ответы для повторного использования.

`ai_contract.py` сейчас реализует покрывающие весь хронометраж окна и проверку монтажных предложений. Сетевой адаптер ещё не подключён. Нельзя называть эту основу работающим AI-режиссёром или обещать понимание каждого кадра. Gemini имеет отдельные правила семплирования видео — их нужно учитывать в испытаниях: [Video understanding](https://ai.google.dev/gemini-api/docs/video-understanding).
