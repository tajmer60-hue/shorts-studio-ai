# OpenRouter: реализованный адаптер, живое испытание отложено

23 октября 2026: пользователь выбрал «Пока только подготовить, без платных запросов». Сетевых запросов с медиа не выполнялось.

Выбран `google/gemini-2.5-flash-lite`: на официальной странице OpenRouter указаны $0.10 за 1 млн входных и $0.40 за 1 млн выходных токенов. Публичный каталог /api/v1/models дополнительно проверен без ключа: модель доступна, контекст 1048576, вход images/video, поддерживается response_format. Это не проверка платного completion. Это тариф токенов, не измеренная цена серии. [Официальная цена](https://openrouter.ai/google/gemini-2.5-flash-lite/pricing).

Адаптер cloud_planner.py отправляет текст с исходными таймкодами и уменьшенные JPEG через /api/v1/chat/completions. auto_workflow.py готовит всю серию, делает оконный и общий отбор, проверяет предложения и запускает реальный монтаж. Обзорные кадры не равны просмотру каждого кадра/звука: динамические события могут быть пропущены. Live API compatibility и качество выбора ещё не подтверждены.

## Включение после согласия на расходы

Создать отдельный ключ в [OpenRouter](https://openrouter.ai/settings/keys), задать лимит на стороне сервиса, вставить в поле приложения. Указать бюджет проекта и включить разрешение передачи реплик/кадров. Ключ на диск не записывается. Бесплатные сторонние ключи не используются.

Модель фиксирована; резерв бюджета ~0.1082 USD на запрос, исходя из полной ёмкости контекста и максимального ответа, а не оптимистичного подсчёта картинок. max_price ограничивает тариф провайдера, fallback выключен. Резерв сохраняется на диске ДО запроса, включая неопределённые ошибки; успешные ответы кэшируются. Это консервативное ограничение числа запросов. Оно не учитывает комиссии пополнения сервиса; отдельный лимит ключа нужен для общего контроля аккаунта. Повторная кнопка не повторяет успешные запросы, но незавершённый запрос может быть отправлен заново только при новой команде и новом резерве.

Один активный проект в обычном приложении защищён существующим QLockFile. Ожидание API до 90 секунд; отмена прекращает следующие шаги, но не отменяет уже переданный запрос или возможное списание. Изменения тарифа приводят к отказу запроса вместо перехода на дорогую модель.

[Параметры маршрутизации/цены](https://openrouter.ai/docs/guides/routing/provider-selection). Автоматический fallback и сбор данных провайдером отключены параметрами запроса; это не обещание отсутствия технического хранения у всех участников обработки.

## Приёмка перед рабочим использованием

Разрешённый live-тест: небольшое видео → фактический ответ модели → валидированные интервалы → смонтированные ролики → ручная проверка смысла, стыков и суммы списания. Затем полная серия. До этого не называть сборку аналогом OpusClip по качеству.
