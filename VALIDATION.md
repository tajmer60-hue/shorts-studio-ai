# Проверки M1

Проверено 22 октября 2026 в рабочем окружении Windows, Python 3.13, PySide6 6.10.2, FFmpeg/FFprobe 9.0.2 (Gyan essentials). Python-зависимости установлены в .venv, FFmpeg/FFprobe в tools; машинные файлы в Git не отправляются.

Команда: `.venv\Scripts\python -m unittest discover -s tests -v`. Все 12 тестов прошли.

Проверки:

- Диапазон внутри исходного видео, отрицательные/нулевые/бесконечные значения.
- Пути с пробелами и Unicode, аргументы без shell.
- Защита существующих результатов и исходника.
- Реальное кодирование синтетического видео: MP4, 1080×1920, длительность, аудиодорожка.
- Crop и исходник без аудиодорожки.
- Отмена до экспорта и после начала обработки; удаление временных файлов.
- SQLite: сохранение pending, running → interrupted после повторного открытия, защита от повторного имени активного задания.
- Создание и закрытие окна PySide6 в offscreen-режиме. Проверка кириллического глифа; при отсутствии перечисляемых шрифтов Windows загружается системный Segoe UI. Исправление проверено по изображению окна.
- Полный конвейер анализа референса на синтетическом видео: отчёт и контактный лист.

На пользовательском эталоне отдельно выполнен FFmpeg-анализ метаданных, кандидатов смены кадров, тишины при двух порогах, громкости, чёрных кадров и cropdetect. Просмотрены контактный лист и три полноразмерных кадра. Исходник не изменялся. Результаты — REFERENCE_ANALYSIS.md.

Ограничения: не проверялись многочасовые/многогигабайтные исходники, повреждённые контейнеры, HDR, VFR, нехватка диска, сбой питания на переносе результата, реальная производительность RTX/NVENC, прослушивание и транскрипция эталона. Не проводилась полная ручная проверка интерфейса на компьютере заказчика. GPU и AI-модели в M1 не используются. Возобновление кодирования с середины и автоматическая очистка файлов после аварии пока не реализованы.

## Подготовка среды AI

После установки AI-зависимостей 12 тестов приложения повторно прошли; pip check не обнаружил конфликтов. Дополнительно verify_ai.py прошёл 7 проверок на синтетических данных и поставляемом с faster-whisper VAD. verify_gpu.py выполнил реальное CUDA/cuBLAS-умножение матриц с проверкой результата и инициализацию cuDNN через локальные библиотеки .venv. Выполнено короткое синтетическое кодирование NVENC совместимой portable-сборкой FFmpeg 7.1 без изменения драйвера. Это проверка доступности среды; производительность на больших видео и полное Whisper-распознавание не проверены. Модели Whisper/vision не скачивались. Инструкции и ограничения — ENVIRONMENT_SETUP.md; персональная диагностика не включена в Git.
