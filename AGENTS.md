# Правила разработки Shorts Studio AI

- Источник требований — Issue #2 и PROJECT_SPEC.md. Прочитать AUDIT.md, ARCHITECTURE.md, PROGRESS.md, README.md перед изменениями.
- Учитывать PRODUCT_DIRECTION.md: качество/смысловой монтаж важнее количества; полное покрытие исходника последовательными блоками не является основным AI-отбором. Не обещать квоту 6–12 роликов независимо от материала.
- Самостоятельно реализовывать и проверять этапы P0–P6 последовательно. Отдельные PR по этапам; не merge без разрешения.
- Не выдавать установленные библиотеки, кнопки, заглушки, synthetic tests или mock outputs за рабочую AI-функцию. Готовность требует реального видео и зафиксированных результатов/ограничений.
- Python, PySide6, FFmpeg/FFprobe, SQLite; анализ, решения EDL и рендер отдельно, схемы версионируются.
- Windows 11, RTX 4070 Laptop 8 GB VRAM, 16 GB RAM; потоковое чтение, proxies, один тяжёлый AI worker; долгие операции вне UI.
- Все проектные файлы, зависимости, модели и cache на D:. Не использовать C: как обход отсутствующих прав. Системные программы/настройки изменять только после разрешения пользователя.
- Бесплатный офлайн-путь приоритетен. Платные API запрещены без разрешения. Видео, кадры и транскрипты не отправлять внешним сервисам.
- Никогда не удалять пользовательские исходники или заменять существующий экспорт. Очищать только собственные временные файлы.
- Checkpoint только после проверки этапа. Проверять identity/version/input перед повторным использованием; не считать interrupted completed. Crash между publish и commit должен быть учтён.
- Тестировать существующий target, мало места, отмену, аварийный перезапуск, кириллицу, silent/corrupt media, время и A/V sync. Synthetic regression дополняет, но не заменяет реальное видео.
- Smart Censor всегда требует ручного QC, неизвестное не считается безопасным; не обещать вирусность/защиту от банов.
- Медиа/модели/cache/БД/ключи/токены не коммитить. Логи не содержат секретов.
- Не публиковать видео без отдельного разрешения. Сохранять прогресс в GitHub и точно указывать, что проверено и что блокируется.
