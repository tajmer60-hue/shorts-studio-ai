# Готовность Shorts Studio AI — матрица приёмки

Составлено 25 октября 2026 по Issue #2 и ТЗ v3. Статус означает то, что
**проверено тестами или реальным прогоном**, а не наличие кнопки.

## Путь пользователя

| Требование | Статус | Как проверено |
|---|---|---|
| Одна кнопка вместо ручных таймкодов | готово | UI-тесты; офлайн-монтаж работает без ключа |
| Автоанализ серии (речь, сцены, кадры) | готово | реальный прогон на серии 61 мин ранее; тесты подготовки |
| Предложения с таймкодами и объяснениями | готово | тесты контракта; реальный бенчмарк-прогон |
| Предпросмотр и сохранение просмотренного | готово | тесты review-потока |
| Очередь задач, восстановление после сбоя | готово (P0) | тесты crash-recovery на реальном видео |

## Монтаж

| Требование | Статус | Как проверено |
|---|---|---|
| Serial Cutter: связные Part 1..N | готово | тесты хронологии, word-safety, причинности |
| Viral Moments: самостоятельные пики | готово | тесты порога интенсивности, непересечения |
| Сокращение пауз без обрыва слов | готово | тесты remap_words; реальный FFmpeg |
| Пропуск заставок/рекапа/титров | готово | тесты мульти-сигнального детектора |
| Smart Reframe без чёрных полос | готово | реальный FFmpeg: объект >5% кадра против <3% у центра |
| Background fill вместо полос | готово | тест wide-subject |
| Ручные keyframes кропа | **нет** | не реализовано |
| Reference Style Analyzer | готово | тесты профиля и ранжирования по темпу |
| Два промпта/алгоритма, а не один | готово | тесты различий режимов |

## Звук и музыка

| Требование | Статус | Как проверено |
|---|---|---|
| Локальный ASR с таймкодами слов | готово | реальные прогоны ранее; 2 теста опциональны без модели |
| Глушение мата по границам слов | готово | реальный FFmpeg: mute в выходном времени |
| Beat Sync: BPM, биты, дропы | готово | тесты на клик-треке 120 BPM |
| Склейки к битам без ущерба сюжету | готово | тесты snap (слова, коллизии) |
| Дакинг музыки под диалог, лимитер | готово | реальный FFmpeg: микс ≤ 0 dB |
| Лицензионно-чистая библиотека | готово | тесты трёх уровней; v1/v2 внесены как CLAIMED |
| Реальные треки в миксе | **ждёт файлов** | файлов нет; микс молчит до импорта |
| Библиотека звуковых эффектов | частично | план и правила готовы; файлов эффектов нет |

## Цензура и QC

| Требование | Статус | Как проверено |
|---|---|---|
| Точечный blur с трекингом | готово (контракт) | тесты clamp/merge/filtergraph |
| Визуальный детектор на реальном видео | **не проверено** | контракт и валидация есть, прогона не было |
| Очередь QC сомнений в UI | готово | тесты очереди; диалог в UI |
| Авто-QC ролика, 6 шкал, 1 авто-поправка | готово | тесты на сломанных артефактах |

## AI и расходы

| Требование | Статус | Как проверено |
|---|---|---|
| Заменяемые провайдеры | готово | тесты цепочки и контрактов |
| Бесплатный путь $0 | готово | реальный прогон: 2 запроса, $0 |
| Живая квота до отправки | готово | тесты FreeQuota; реальный GET /api/v1/key |
| Оценка цены до запроса | готово | тесты тарифов; неизвестный тариф = «неизвестно» |
| Бенчмарк качество/цена | частично | 1 реальный прогон текста; кадры и реальное видео не оценены |

## Инфраструктура

| Требование | Статус | Как проверено |
|---|---|---|
| Профили каналов (3 + свои) | готово | тесты валидации и маппинга |
| Экспорт MP4 1080×1920, NVENC | частично | libx264 проверен; NVENC не проверен на вашем GPU |
| Portable-сборка Windows | частично | списки обновлены; сборка не пересобиралась |
| Испытание >5 ГБ и восстановление | **на вашей машине** | механика P0 проверена на коротких файлах |
| Приёмка на реальной серии | **на вашей машине** | требует прослушивания и просмотра человеком |

## Итого

Готово к вашей приёмке на реальном материале. Не завершены: ручные keyframes
кропа, файлы музыки и эффектов, реальное испытание визуальной цензуры,
пересборка portable, NVENC и большие файлы на вашем железе.
