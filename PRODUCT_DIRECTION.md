# Уточнение заказчика — 22 октября 2026

Основной продукт — самостоятельный качественный монтаж: отбор, сокращение, осмысленные склейки и музыкальное оформление. Последовательная нарезка всей серии остаётся отдельной вспомогательной функцией, не основным результатом.

- Ориентир 6–12 сильных роликов из серии, но без квоты. Если достойных моментов меньше, не заполнять количество слабыми.
- Сохранять причинно-следственную связность и характер персонажей. Убирать лишние паузы и запинки без обрыва слов и подмены смысла; осмысленные реакции оставлять.
- Кроп сопровождает говорящего, персонажа и действие. Общий план выбирается по композиции сцены, не как случайный fallback при потере детектора. Низкая уверенность требует проверки.
- Локальные маски крови/травм и других чувствительных областей; mute ненормативной лексики по границам слов. Музыка отдельной дорожкой, с правами на использование.
- Единый монтаж для Shorts, Reels, TikTok с профилями формата/безопасных зон. Приоритет — удержание и качество, а не обещание просмотров или монетизации.
- Эталон находится локально: references/example.mp4. Не загружать видео в GitHub. Его уже плотный монтаж не служит достаточным тестом удаления пауз — нужны также более медленные исходные реплики.
- Пользователь допускает недорогой API в будущем. Это согласие обсуждать интеграцию, не разрешение на расходы/отправку видео. Перед платными запросами согласовать провайдера, бюджет и данные. Основной бесплатный локальный путь сохраняется.

Последовательность Issue #2 сохраняется: P1 речь/таймкоды → P2 сопровождение кадра → P3 смысловой монтаж/музыка → P4 точечная цензура. Lite-блоки текущей версии — техническая промежуточная функция, не итоговый алгоритм отбора.
