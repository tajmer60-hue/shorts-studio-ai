# Прогресс — Issue #2

## 24 октября: редакторская логика AI

- Добавлен story_brain.py: карта событий каждого окна → общий монтажный план → отдельная редакторская проверка. Карта ссылается на реальные ID реплик и таймкоды выборочных кадров; неизвестные ссылки отклоняются.
- План использует только интервалы известных событий; проверка читает также окружающие реплики ±12 с, чтобы учитывать вырезанный контекст. Каждый ролик обязан получить заключение по связности, целым репликам, контексту и повторам. Отрицательное заключение исключает ролик из рендера.
- Причины отклонений, карта, черновик и проверка сохраняются локально. Это проверки структуры и дополнительный проход модели, не доказанная гарантия смысловой правильности.
- Подключение OpenRouter через PKCE без копирования ключа: loopback 127.0.0.1, проверка state, ключ не выводится. Опциональное сохранение DPAPI текущего пользователя Windows. Проверены локальный callback, отклонение неправильного state и зашифрованное хранение на Windows.
- Кэш запросов разделён по промптам этапов. Резерв свежего проекта учитывает N окон + два общих прохода.
- Проверки: 69 тестов, 68 прошли, 1 опциональный тест речи пропущен. Добавлены случаи неизвестных доказательств, вымышленных интервалов, отсутствующего/повторного заключения и отклонения несвязной истории.
- Live API не вызывался: расходы всё ещё запрещены. В OpenRouter требуется вход пользователя; страница входа открыта. Контрактные тесты используют фикстуры и не считаются испытанием качества AI.
